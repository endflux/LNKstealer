# ChromElevator — File Structure & Workflow

## File Structure

```
Chrome-App-Bound-Encryption-Decryption/
│
├── make.bat                          # Build orchestrator (replaces CMake/MSBuild)
│
├── src/
│   ├── core/
│   │   ├── common.hpp                # Shared types, string utils (ToUtf8), TIMEOUT_MS constant
│   │   ├── console.hpp               # Colored terminal output (Banner, BrowserHeader, Summary, Error, Warn, Debug)
│   │   ├── obfuscate.hpp             # Compile-time string obfuscation macros
│   │   └── version.hpp              # Version string
│   │
│   ├── crypto/
│   │   ├── chacha20.cpp/.hpp         # ChaCha20 stream cipher — decrypts embedded payload at runtime
│   │   ├── aes_gcm.cpp/.hpp          # AES-256-GCM — decrypts browser cookie/password/payment blobs
│   │   ├── key_derivation.hpp        # Compile-time key derivation from build metadata
│   │   └── crypto.hpp                # Unified crypto interface
│   │
│   ├── sys/
│   │   ├── internal_api.cpp/.hpp     # Hell's Gate syscall engine: parses ntdll, resolves SSNs via DJB2 hashing
│   │   │                             # Exports: NtAllocateVirtualMemory_syscall, NtWriteVirtualMemory_syscall,
│   │   │                             #          NtProtectVirtualMemory_syscall, NtCreateThreadEx_syscall,
│   │   │                             #          NtTerminateProcess_syscall, NtDuplicateObject_syscall, etc.
│   │   │                             # InitApi() called first by both injector and payload
│   │   ├── bootstrap.cpp/.hpp        # Reflective PE loader — maps DLL sections, fixes relocations,
│   │   │                             # resolves IAT via PEB walk, destroys PE headers post-load
│   │   ├── syscall_trampoline_x64.asm   # x64 syscall gadget (syscall/ret stub)
│   │   └── syscall_trampoline_arm64.asm # ARM64 syscall gadget (svc/ret stub)
│   │
│   ├── com/
│   │   ├── elevator.cpp/.hpp         # COM interface wrapper — instantiates IElevator / IElevator2 /
│   │   │                             # IEdgeElevatorFinal / IAvastElevator and calls DecryptData()
│   │   │                             # to obtain the plaintext AES-256 master key from the ABE COM server
│   │
│   ├── injector/
│   │   ├── injector_main.cpp         # Entry point (wmain) — arg parsing, calls InitApi, loops browsers,
│   │   │                             # calls ProcessBrowser() for each target
│   │   ├── browser_discovery.cpp/.hpp # Finds browser install paths + versions (FindAll / FindSpecific)
│   │   ├── browser_terminator.cpp/.hpp# KillByExeName() — NtTerminateProcess syscall on all matching PIDs
│   │   ├── process_manager.cpp/.hpp  # CreateSuspended() — spawns browser in CREATE_SUSPENDED state;
│   │   │                             # holds HANDLE for later Terminate()
│   │   ├── pipe_server.cpp/.hpp      # Named pipe server — Create, WaitForClient, SendConfig, ProcessMessages
│   │   │                             # Generates browser-mimicking pipe name; reads log/data messages from payload
│   │   ├── injector.cpp/.hpp         # PayloadInjector — decrypts embedded payload, resolves Bootstrap export,
│   │   │                             # allocates+writes+protects memory via syscalls, NtCreateThreadEx to Bootstrap
│   │
│   ├── payload/
│   │   ├── payload_main.cpp          # DllMain + PayloadThread — connects pipe, reads config, calls COM elevator,
│   │   │                             # drives DataExtractor across all profiles, optionally runs fingerprinter
│   │   ├── browser_config.hpp        # GetConfigs() — maps browser type string to userDataPath, clsid, iid, iid_v2
│   │   ├── data_extractor.cpp/.hpp   # ProcessProfile() — opens SQLite DBs (Cookies, Login Data, Web Data)
│   │   │                             # via duplicated handles, decrypts AES-GCM blobs, writes JSON output files
│   │   ├── handle_duplicator.cpp/.hpp# NtDuplicateObject syscall — copies file handles to bypass SQLite file locks
│   │   ├── pipe_client.cpp/.hpp      # Named pipe client — IsValid, ReadConfig, Log, LogDebug helpers
│   │   └── fingerprint.hpp           # FingerprintExtractor — gathers browser version, extensions, system info
│   │
│   └── tools/
│       └── encryptor.cpp             # Build-time tool: reads compiled payload DLL, ChaCha20-encrypts it,
│                                     # emits payload_data.hpp as a C++ byte-array header
│
├── libs/
│   └── sqlite/
│       ├── sqlite3.c                 # SQLite3 amalgamation (bundled, statically compiled)
│       └── sqlite3.h
│
├── build/                            # Generated by make.bat (not checked in)
│   ├── payload_data.hpp              # Generated: encrypted payload as constexpr byte array
│   ├── chrome_decrypt.dll            # Intermediate payload DLL
│   ├── encryptor.exe                 # Build-time encryptor tool
│   └── *.obj                         # Compiled object files
│
├── tools/                            # Python analysis / research utilities
│   ├── comrade_abe.py                # COM vtable analysis tool
│   ├── browser_processes.py          # Browser process enumeration helper
│   ├── abe_key_extract/              # Standalone key extraction helper
│   └── *_data.json                   # Per-browser vtable/offset snapshots (chrome-144, edge-145, etc.)
│
└── docs/
    ├── RESEARCH.md
    ├── COMrade_ABE_Field_Manual.md
    ├── The_Curious_Case_of_the_Cantankerous_COM_Decrypting_Microsoft_Edge_ABE.md
    └── The_Elevator_Gets_an_Upgrade_Chrome_144_IElevator2_and_the_Mojo_Horizon.md
```

## Build Workflow

```
make.bat (full build)
    │
    ├─ 1. cl.exe → sqlite3.obj
    │         libs/sqlite/sqlite3.c
    │
    ├─ 2. cl.exe → chrome_decrypt.dll   (payload, compiled as DLL)
    │         src/sys/bootstrap.cpp
    │         src/sys/internal_api.cpp
    │         src/sys/syscall_trampoline_x64.asm  (or arm64)
    │         src/com/elevator.cpp
    │         src/crypto/aes_gcm.cpp
    │         src/payload/payload_main.cpp
    │         src/payload/data_extractor.cpp
    │         src/payload/handle_duplicator.cpp
    │         src/payload/pipe_client.cpp
    │         sqlite3.obj
    │
    ├─ 3. cl.exe → encryptor.exe
    │         src/tools/encryptor.cpp
    │         src/crypto/chacha20.cpp
    │
    ├─ 4. encryptor.exe chrome_decrypt.dll → build/payload_data.hpp
    │         ChaCha20-encrypts the DLL with compile-time derived key
    │         emits:  constexpr uint8_t Data[] = { ... };
    │                 constexpr size_t  Size   = ...;
    │
    └─ 5. cl.exe → chromelevator.exe   (injector, includes payload_data.hpp)
              src/sys/internal_api.cpp
              src/sys/syscall_trampoline_x64.asm  (or arm64)
              src/crypto/chacha20.cpp
              src/crypto/key_derivation.hpp
              src/injector/injector_main.cpp
              src/injector/browser_discovery.cpp
              src/injector/browser_terminator.cpp
              src/injector/process_manager.cpp
              src/injector/pipe_server.cpp
              src/injector/injector.cpp
              build/payload_data.hpp  (baked-in encrypted payload)
```

## Runtime Workflow

```
chromelevator.exe <browser> [options]
    │
    ├─ 1. Sys::InitApi()
    │       Parses ntdll.dll in memory
    │       Resolves syscall numbers (SSNs) via DJB2 hash matching
    │       Locates syscall/ret gadgets for x64 (or svc/ret for ARM64)
    │
    ├─ 2. BrowserDiscovery::FindAll() / FindSpecific()
    │       Locates browser install path + reads version from resources
    │
    ├─ [optional] BrowserTerminator::KillByExeName()
    │       NtGetNextProcess → NtTerminateProcess on all matching PIDs
    │       Releases SQLite file locks held by live browser instances
    │
    ├─ 3. ProcessManager::CreateSuspended()
    │       CreateProcessW(browser.exe, CREATE_SUSPENDED)
    │       Browser spawned as a clean, trusted host — no code runs yet
    │
    ├─ 4. PipeServer::Create()
    │       CreateNamedPipeW with a browser-IPC-mimicking name
    │
    ├─ 5. PayloadInjector::Inject()
    │       a. ChaCha20-decrypt embedded payload byte array → plaintext DLL in local memory
    │       b. Resolve "Bootstrap" export offset from PE headers
    │       c. NtAllocateVirtualMemory  — allocate RW memory in suspended process
    │       d. NtWriteVirtualMemory     — write decrypted DLL + pipe name into remote memory
    │       e. NtProtectVirtualMemory   — flip region to PAGE_EXECUTE_READ
    │       f. NtCreateThreadEx         — start thread at Bootstrap export, pipe name as argument
    │          (browser's original main thread stays suspended forever)
    │
    ├─ 6. PipeServer::WaitForClient() + SendConfig()
    │       Blocks until payload connects back
    │       Sends: verbose flag, fingerprint flag, output path, browser type string
    │
    │   ═══════════ PAYLOAD SIDE (running inside browser process) ═══════════
    │
    │   Bootstrap() — reflective PE loader
    │       Allocates new memory via NtAllocateVirtualMemory syscall
    │       Maps DLL sections, fixes base relocations
    │       Resolves IAT by walking PEB (no GetProcAddress)
    │       Sets section permissions via NtProtectVirtualMemory
    │       Destroys PE headers (overwrites MZ/NT headers with random bytes)
    │       Calls DllMain
    │
    │   DllMain → spawns PayloadThread
    │
    │   PayloadThread:
    │       a. PipeClient::connect → reads config (output path, browser type, flags)
    │       b. Sys::InitApi() again (inside browser process)
    │       c. Read Local State → extract app_bound_encrypted_key (base64 → bytes)
    │       d. Com::Elevator::DecryptKey()
    │              CoCreateInstance(browser CLSID)
    │              QI for IElevator2 (Chrome/Brave 144+) or IElevator / IEdgeElevatorFinal / IAvastElevator
    │              Call DecryptData() — COM server validates caller path → passes (we ARE the browser)
    │              Returns plaintext AES-256 master key
    │       e. DataExtractor::ProcessProfile() for each profile directory
    │              HandleDuplicator::Duplicate() — NtDuplicateObject to copy locked DB file handles
    │              Open Cookies / Login Data / Web Data via duplicated handles
    │              SQLite3 query → encrypted blobs
    │              AES-256-GCM decrypt each blob with master key
    │              Serialize to JSON → write to output/<Browser>/<Profile>/
    │       f. [optional] FingerprintExtractor::Extract()
    │       g. Send __DLL_PIPE_COMPLETION_SIGNAL__ over pipe
    │       h. FreeLibraryAndExitThread
    │
    │   ═══════════════════════════════════════════════════════════════════
    │
    └─ 7. PipeServer::ProcessMessages()
            Reads log lines + data stats from pipe until completion signal
            Prints summary: cookies / passwords / cards / IBANs / tokens per profile
            ProcessManager::Terminate() — NtTerminateProcess on hollow host
```

## Data Flow Summary

```
Local State (JSON)
    └─ app_bound_encrypted_key (base64)
            │
            ▼
    Com::Elevator::DecryptKey()   ← runs inside browser process, passes COM path check
            │
            ▼
    AES-256 master key (32 bytes)
            │
            ├─► Cookies DB  (SQLite) ──► AES-256-GCM decrypt ──► cookies.json
            ├─► Login Data  (SQLite) ──► AES-256-GCM decrypt ──► passwords.json
            └─► Web Data    (SQLite) ──► AES-256-GCM decrypt ──► payments.json / ibans.json
```
